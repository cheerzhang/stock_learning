# 仓鉴

一个以欧元为金额单位的私人投资分析看板，适合直接部署到 GitHub Pages。数据集中保存在 `public/portfolio-data.json`。

## 使用

```bash
npm install
npm run dev
```

打开页面后：

1. 点击「添加资产」，输入第一天的持仓总价值和截至当天的累计收益；系统自动计算本金。平均买入价可选。
2. 点击「记录当天价值 / 投入」，填写账户中该资产当天显示的持仓总价值；有新增投入时一并填写。
3. 新增投入增加本金但不算收益，看板会自动更新收益、收益率和贡献分析。

同一资产、同一日期再次保存时，会覆盖当天的旧记录。周末和休市日无需填写；第一条价格记录就是历史起点。本地开发模式下，页面上的修改会自动写入 `public/portfolio-data.json`；线上页面只读取这个文件，不提供编辑入口。

## 计算口径

- 本金 = 第一条持仓总价值 − 截至第一天的累计收益
- 当前本金 = 初始本金 + 后续累计新增投入
- 当前累计收益 = 初始累计收益 + 持仓价值变化 − 后续累计新增投入
- 收益率 = 当前累计收益 ÷ 当前本金
- 总贡献 = 单项资产累计收益 ÷ 全部资产累计收益

## 发布到 GitHub Pages

在 GitHub 仓库的 **Settings → Pages → Source** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/(root)`。

每次本地更新数据后运行 `npm run build`，构建会把可直接发布的网站生成到仓库根目录。提交并推送 `main` 后，GitHub Pages 会直接发布根目录内容。
